# NavJev project page

Local project page for **NavJev: Efficient Vision-Language Navigation via Action-Centric Visual Compression and Discriminative Action-Semantic Memory**.

The static project page is hosted with GitHub Pages at https://kai-sheng-caesar.github.io/NavJev/. The NavJev code is being reviewed locally and has not been uploaded. The Code button remains disabled until release is authorized.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.

## Files to update before release

- Keep the Code links aligned with the simulation repository and its access status.
- Update the BibTeX block and scholarly metadata when an arXiv ID or venue is available.
- Add the final public project URL to Open Graph metadata after the GitHub Pages repository is chosen.

## GitHub Pages

When the page is ready to become public, push this directory to the desired GitHub repository and select **Settings → Pages → Deploy from a branch**, using the repository's default branch and the root directory.
